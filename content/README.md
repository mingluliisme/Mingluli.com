# 内容源文件

网页上「随想」「生活」「写作」三个区块的内容都在这个目录里，
由仓库根目录的 `build.py` 生成到 `index.html`。

**改完 Markdown → 运行一次构建 → 打开网页看效果。**

构建方式（任选一种）：

```
python build.py
```

或者直接双击仓库根目录的 `build.bat`。

---

## 加一条随想 / 生活

在 `notes/` 或 `life/` 下新建文件，**文件名必须以日期开头**：

```
notes/2026-11-07-随手记.md
```

文件内容：

```markdown
---
date: 2026-11-07
---

正文第一段。

正文第二段。
```

- 日期决定排序，最新的自动排最上面，不用手动调整顺序
- `date` 可以不写，脚本从文件名取
- 空行分段；段落内的单个换行会被合并成同一段，不会多出一个空格
- 支持 `**粗体**`、`*斜体*`、`[文字](链接)`

## 加一篇写作

在 `writing/` 下新建文件，文件名 `年-月-标题.md`：

```
writing/2026-10-人机决策中的信任校准.md
```

文件内容：

```markdown
---
date: 2026-10
status: 撰写中
summary: 一句话说明这篇文章写了什么。
link:
---

# 人机决策中的信任校准
```

- `status` 可写：计划中 / 撰写中 / 已完稿 / 已发布。留空则只显示日期
- `link` 填文章地址；留空时显示为 `#`（点了跳页顶）
- 一级标题 `# xxx` 就是网页上显示的标题

## 删掉一条

直接删掉对应的 `.md` 文件，重新构建即可。

## 不要做的事

- **不要手改 `index.html` 里 `AUTO-GENERATED` 注释之间的内容**，下次构建会整段覆盖
- 注释之外的部分（Hero、我的概况、科研、联系方式、页脚）随便手改，构建不会碰
- 不要把 `content/` 里的文件删空了还去跑构建 —— 区块会变空，但不会报错
